Privacy Policy

updated aug 15 2026

This policy explains what data Banana ("the bot") collects and how it's used.

1. Data we collect

  • Discord IDs (user, server, channel) needed to process commands.
  • Warning records: the warned user's ID, the moderator's ID, the reason given, and the date, stored per server.
  • Basic command usage, for error logging and debugging.

2. What we don't collect

Banana doesn't read or store the content of regular messages, DMs, or attachments. Message content is only ever seen transiently to process a command (e.g. purge), and isn't logged.

3. How data is used

Data is used solely to operate the bot's features — for example, showing a user's warning history or logging moderation actions for server staff.

4. Data retention

Warning records are kept until a server admin removes them or the bot is removed from the server. You can request deletion of a server's data by contacting us through the support server.

5. Data sharing

We don't sell or share collected data with third parties. Some commands (cat images, dad jokes, Urban Dictionary lookups) send your search term to that third-party API to fetch a result — no other data is sent.

6. Security

We take reasonable steps to protect stored data, but no system is fully secure. Use the bot with that in mind.

7. Your rights

Server admins can request their server's stored data be deleted at any time via the support server.

8. Changes

This policy may be updated at any time. Continued use of the bot after changes means you accept the new policy.

9. Contact

Questions about this policy can be directed to the support server.
