Banana

A Discord bot with moderation, info, and fun commands.

Invite to Server Support Server

Moderation

Command Description
/ban Bans a member from the server.
/kick Kicks a member from the server.
/mute Times out a member for a set duration.
/unmute Removes a member's timeout.
/warn Warns a member and logs it.
/warnings Shows a member's warning history.
/purge Deletes a number of recent messages.
/lock Prevents @everyone from sending messages here.
/unlock Restores @everyone's ability to send messages here.
/nickname Changes a member's nickname.

Info

Command Description
/about Shows Banana's information.
/help Shows all commands, or details about one.
/ping Shows API, websocket, and database latency.
/userinfo Shows information about a user.
/serverinfo Shows information about this server.
/channelinfo Shows information about a channel.
/roleinfo Shows information about a role.

Fun

Command Description
/banana Sends Banana's custom emoji.
/banana fact Sends a random banana fact.
/cat Sends a random cat image.
/dadjoke Sends a random dad joke.
/urban Searches Urban Dictionary for a word.
